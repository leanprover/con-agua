# Deviations of L from its twin

L is a close twin of con-ron (and through it con-leche). This file lists every place where L
does something else than its twin, beyond fuel and fixed capacities (an array or memo table
that is full aborts by design). **Rule (PLAN.md):** a lane that introduces a deviation adds
its row to `## Temporary` or `## Deliberate` in the same commit; the coordinator reviews the
list.

Three sections. **Temporary**: L currently does something else and we intend to fix it
(missing code, aborts "for now", stubs, unported arms, harness-only limits meant to go away);
rows whose intent is unclear are listed here too. **Deliberate**: by design and staying; the
fix column says why. **Fixed**: history, one line each.

Effect: **completeness** = L aborts (declines) on inputs the twin accepts; **performance** =
same verdicts, more work or memory; **none** = representation only. A deviation never may be a
soundness loss; one that could become one is marked **(!)**.

Audit: 2026-10-22, lane `twinaudit`, restructured by classification. Deduplicated 2026-10-24
(lane `polish`, after lane `audit`): one row per deviation. D18 is one row for all the
`sl_cons`-built lists; the string-literal pool words are D24 (once also listed as D21 and D26);
D21 is `proj_table_name`'s pool words; the second D28 (`StubNames`) is now D28b. The Fixed entry
"D18/D24" (`hoist_ok`) is an older use of those two ids.

## Fixed

- **D4** (fixed by lane consync, helper consync-pins): con-ron ed864140 retired `orElseAttempt` (its task #129): an error inside a pin-variant attempt is the run's error in the twin too, and L's loop is the twin's boolean decision loop (`check_div_mod_pin_loop`); the attempt flag `ATT` and the `fail R` class masking are gone.
- **D21, D22, D29** (fixed by lane consync, the twin bump to con-ron `ed864140`): the projection tables left the constants (con-leche task #362): no reserved table name is interned any more (`proj_table_name` is gone; tables are keyed on the structure name in the environment's table component, `find_table`), and no constant is a projection table (the ROM reader has no kind `6` to refuse).
- **D39** (fixed by lane epochwrap): `scratch_reset` aborted after `2^30` resets (the slot base `B = CTL[62]` at `2^62`); now at `B ≥ 2^62` it vacates the 19 scratch slot tables (the growth's zero loop `kzeroLs`) and restarts `B` at `0`, as con-ron's `HashMap2::clear` at `EPOCH_MAX` (docs/design/epochwrap.md).
- **D35** (fixed by lane tierswitch): every store keeps one word array per tier (tier `t` of array `a` is `a + 256`, lane tierarr's `ld64t`/`st64t`): records `ra⟨t⟩[i * w + f]`, slot tables `sa⟨t⟩` (one KSTP formula per tier array), derived and level-parameter columns `col⟨t⟩[i]`, as con-ron's per-tier `Tbl`s (docs/design/tierswitch.md).
